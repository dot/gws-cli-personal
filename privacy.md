# Privacy Policy

This OAuth client is used by a single person to access their own Google Drive and Google Calendar data from a command-line tool.

- Data is fetched directly from Google APIs to the owner's local machine.
- No data is sent to, stored on, or shared with any server operated for this client.
- No data is collected from anyone other than the owner.
- Access can be revoked at any time at https://myaccount.google.com/permissions

Contact: via the GitHub account that hosts this page.
